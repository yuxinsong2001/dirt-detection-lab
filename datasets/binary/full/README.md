# Full Binary Dataset Layout

Place the full 2-class YOLO dataset here. Images and labels must use matching filenames.

```text
datasets/binary/full/
├── images/
│   ├── train/
│   ├── val/
│   ├── test_real_new/
│   ├── blended_test_floor_images/
│   ├── blended_test_floor_images_dirt_only/
│   └── blended_training_floor_images/
└── labels/
    ├── train/
    ├── val/
    ├── test_real_new/
    ├── blended_test_floor_images/
    ├── blended_test_floor_images_dirt_only/
    └── blended_training_floor_images/
```
